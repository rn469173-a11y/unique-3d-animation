# 12 — Glossary of 3D Animation Terms

> Plain-language definitions for beginners. Alphabetical. Suggested Kannada equivalents are given for a few core terms. Most Indian studios use the English terms.

| Term | Meaning |
|---|---|
| **2.5D** | 2D artwork arranged in 3D space, or 3D made to look 2D |
| **AAA** | Big-budget video games from major studios |
| **Alembic (.abc)** | File format for baked animated geometry passed between software |
| **Albedo / Base colour** | The pure colour of a surface without lighting |
| **Ambient Occlusion (AO)** | Soft shadowing where surfaces meet (corners, creases) |
| **Animatic** | Storyboard images timed to sound: a rough "moving storyboard" |
| **Animation** (ಅನಿಮೇಷನ್ / ಚಲನಚಿತ್ರಣ) | Creating the illusion of movement from a sequence of images |
| **Anticipation** | A small opposite movement before the main action |
| **AOV / Render pass** | Separate image layers (diffuse, specular, shadows) for compositing |
| **AR (Augmented Reality)** | Digital 3D objects overlaid on the real world through a phone or glasses |
| **Arc** | The curved path most natural movements follow |
| **Armature** | Blender's word for a skeleton/rig |
| **Asset** | Any reusable 3D element: character, prop, set |
| **AVGC-XR** | Animation, Visual Effects, Gaming, Comics and Extended Reality (the Indian government's term for the sector) |
| **Baking** | Pre-calculating details (lighting, high-poly detail, simulations) into textures or caches |
| **Bevel** | Rounding sharp edges for realism |
| **Blend shape / Shape key / Morph target** | Stored deformations of a mesh, used for facial expressions |
| **Blocking** | First animation pass with key poses only |
| **Boolean** | Combining or cutting meshes (union, difference, intersect) |
| **Bounding box** | Invisible box enclosing an object |
| **Breakdown** | (1) An in-between key pose; (2) a video showing how a shot was built layer by layer |
| **Camera tracking / Matchmove** | Recreating real camera motion in 3D to add CG to live footage |
| **Caustics** | Light patterns focused through glass or water |
| **Cel-shading / Toon shading** | Rendering 3D to look like flat 2D cartoon art |
| **CFX** | Character effects: cloth, hair, muscle simulation |
| **CGI** | Computer-Generated Imagery |
| **Chroma key / Green screen** | Filming against green/blue so the background can be replaced |
| **Clay render** | Grey, untextured render that shows form and lighting |
| **Compositing** | Combining multiple image layers into the final shot |
| **Constraint** | A rule that controls one object's motion with another |
| **Crowd simulation** | Software-driven animation of many characters |
| **Cycles / EEVEE** | Blender's path-traced and real-time render engines |
| **DCC** | Digital Content Creation software (Maya, Blender, Houdini) |
| **Demo reel / Showreel** | Short video of an artist's best work, used for job applications |
| **Denoising** | Removing render grain/noise, often with AI |
| **Depth of field (DOF)** | Background/foreground blur like a real camera lens |
| **Displacement map** | Texture that physically pushes geometry to add detail |
| **Dope sheet** | Timeline view of keyframes |
| **Dynamics** | Physics simulation (rigid bodies, cloth, fluids) |
| **Edge loop** | A continuous ring of edges; critical for good deformation |
| **Ease in / Ease out** | Slow-in / slow-out acceleration at the start and end of motion |
| **Environment artist** | Creates 3D worlds and sets |
| **Extrude** | Pulling a face or edge outward to create new geometry |
| **Face / Polygon** | A flat surface bounded by edges (tris, quads, n-gons) |
| **FBX** | Common file format for models and animation exchange |
| **FK / IK** | Forward Kinematics (rotate each joint down the chain) / Inverse Kinematics (move the hand or foot and joints follow) |
| **Follow-through** | Parts continuing to move after the main action stops |
| **Frame** (ಫ್ರೇಮ್ / ಚೌಕಟ್ಟು) | One single image in an animation |
| **FPS (frames per second)** | Speed of playback. 24 (film), 25 (Indian TV/PAL), 30/60 (web/games) |
| **Frame rate** | See FPS |
| **Gaussian splatting** | Technique that builds photoreal 3D scenes from photos using millions of tiny blobs |
| **Geometry nodes** | Blender's node-based procedural modelling system |
| **Gimbal lock** | A rotation problem where two axes align and one degree of freedom is lost |
| **glTF / GLB** | Efficient 3D format for web and AR ("the JPEG of 3D") |
| **GPU** | Graphics Processing Unit; accelerates viewport and rendering |
| **Graph editor / F-curves** | Editor for adjusting animation curves and timing |
| **Grooming** | Creating hair/fur on characters |
| **HDRI** | High Dynamic Range Image used to light scenes realistically |
| **Hard-surface modelling** | Modelling mechanical/man-made objects |
| **High-poly / Low-poly** | Detailed vs lightweight versions of a model |
| **In-between / Tweening** | Frames between two key poses |
| **Keyframe** | A frame where the animator sets a specific value or pose |
| **Kinematics** | The study of motion (see FK/IK) |
| **Layout** | Placing cameras, characters and sets per shot |
| **LOD (Level of Detail)** | Multiple model versions at different detail levels (games) |
| **Look-dev** | Developing the final look of assets: materials and shaders |
| **Lip-sync** | Matching mouth shapes to dialogue |
| **Mesh** (ಜಾಲ) | 3D shape made of vertices, edges and faces |
| **MetaHuman** | Epic Games' tool for photoreal digital humans |
| **Mocap (Motion capture)** | Recording real movement and applying it to a 3D character |
| **Modelling** (ಮಾದರಿ ರಚನೆ) | Building 3D shapes |
| **Modifier** | Non-destructive operation applied to a mesh (Blender) |
| **Motion blur** | Blur from fast movement, for realism |
| **Motion graphics** | Animated graphic design: text, logos, infographics |
| **NeRF** | Neural Radiance Field; AI method for creating 3D scenes from images |
| **Normal map** | Texture that fakes surface detail by changing how light bounces |
| **NPR** | Non-Photorealistic Rendering: stylised, painterly or toon looks |
| **NURBS** | Mathematically smooth curves and surfaces |
| **Overlapping action** | Different body parts moving at different rates |
| **Particle system** | Many small points for rain, sparks, dust, crowds |
| **PBR** | Physically Based Rendering: materials that behave like real-world surfaces |
| **Photogrammetry** | Creating 3D models from many photos of a real object |
| **Pipeline** | The sequence of steps and tools in a production |
| **Pivot / Origin** | Point an object rotates and scales around |
| **Playblast / Viewport preview** | Quick low-quality animation preview |
| **Polycount** | Number of polygons in a model |
| **Pose-to-pose** | Animating key poses first, then filling in-betweens |
| **Previs** | Pre-visualisation: rough 3D version of scenes before production |
| **Primitive** | Basic shape (cube, sphere, cylinder) |
| **Procedural** | Generated by rules and algorithms rather than by hand |
| **Ray tracing / Path tracing** | Rendering by simulating light rays bouncing around a scene |
| **Real-time rendering** | Rendering instantly (games, Unreal, EEVEE) |
| **Render** (ರೆಂಡರ್) | The computer's calculation of the final image |
| **Render farm** | Network of computers rendering frames in parallel |
| **Retopology** | Rebuilding a clean, low-poly mesh over a detailed sculpt |
| **Rig / Rigging** (ಅಸ್ಥಿಪಂಜರ ರಚನೆ) | Skeleton and controls that let a model be animated |
| **Rotoscoping (Roto)** | Tracing objects frame by frame to cut them out |
| **Roughness / Glossiness** | How blurry or sharp reflections are |
| **Scene** | A collection of objects, lights and cameras |
| **Sculpting** | Shaping models like digital clay |
| **Secondary action** | A supporting action that adds life |
| **Shader** | Program that defines how a surface looks under light |
| **Skinning / Weight painting** | Defining how a mesh follows the bones of a rig |
| **Squash and stretch** | Deforming to show weight and elasticity |
| **Storyboard** (ಕಥಾಫಲಕ) | Comic-style drawings planning each shot |
| **Subdivision surface** | Smoothing a mesh by adding geometry |
| **Subsurface scattering (SSS)** | Light passing through skin, wax and leaves for realism |
| **TD (Technical Director)** | Technical artist who solves problems and builds tools |
| **Texture** | Image mapped onto a 3D surface |
| **Timeline** | Track showing frames over time |
| **Timing** | Number of frames an action takes, which defines speed and weight |
| **Topology** | The flow and arrangement of polygons on a mesh |
| **Turnaround / Turntable** | Rotating view of a model (360°) for presentation |
| **USD** | Universal Scene Description: Pixar's open standard for 3D scenes |
| **UV mapping / Unwrapping** | Flattening a 3D surface to 2D for texturing |
| **Vertex** | A single point in 3D space; the building block of meshes |
| **VFX** | Visual Effects: CG added to live-action footage |
| **Viewport** | The 3D work window in software |
| **Virtual production** | Filming with real-time 3D environments on LED walls |
| **Volumetrics** | Fog, smoke and light rays rendered in 3D space |
| **VR (Virtual Reality)** | Fully immersive 3D environment through a headset |
| **Walk cycle** | Looping animation of a character walking; a classic exercise |
| **Wireframe** | View showing only the edges of a mesh |
| **XR** | Extended Reality: AR + VR + MR |
| **Z-depth** | Distance information from camera, used for fog and DOF in compositing |
